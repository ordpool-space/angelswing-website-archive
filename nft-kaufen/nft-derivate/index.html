NFT kaufen – die vollständige Anleitung

NFT-Derivate

Read this in English

Will oder kann man in der Finanzwelt keine ganze Aktie erwerben, so bieten bestimmte Broker auch Teilaktien (Fractional Shares) an.
Gibt es Fractional Shares auch für Non-Fungible Token (NFT)?

Setzt man in der Finanzwelt auf steigende Kurse, so erwirbt man den entsprechenden Vermögenswert. Diesen kann man dann später mit Gewinn verkaufen. Das Gegenteil ist ebenso möglich. Auf fallende Kurse zu setzen nennt man einen Leerverkauf (Short-Selling). Vereinfacht gesagt leiht man sich hierfür Vermögenswerte und verkauft diese in der Hoffnung, sie vor dem Rückgabetermin günstiger zurückkaufen zu können (Margin-Trading). Leiht man sich per Kredit mehr Vermögenswerte als man als Kapitel einsetzt, so spricht man von einem Hebel-Geschäft (Leverage). Mögliche Gewinne und Verluste potenzieren sich entsprechend.
Gibt es Short-Positionen auch für Non-Fungible Token (NFT)?

In diesem Artikel wollen wir daher betrachten…

  1. Wie man mit geringem Kapitaleinsatz Anteile an einen hochpreisigen NFT erwerben kann.
  2. Wie man auf fallende Kurse bei einem NFT setzen kann.

Fraktionierte NFT

Nur wenige Menschen besitzen das notwendige Kapital, um in ein berühmtes NFT-Projekt wie die Crypto-Punks oder die Bored Ape zu investieren. Und selbst wenn das notwendige Kapital aufgebracht werden könnte: Jedes Portfolio sollte divers aufgestellt sein. Ein extrem hochpreisiger NFT steht dem im Wege. Wie ist es also möglich, an der Wertentwicklung zu partizipieren? Man benötigt einen Bruchteil einer eigentlich unteilbaren Sache. Es ist aber technisch unmöglich, ein NFT zu teilen. Doch selbstverständlich hat die Crypto-Welt längst einen Weg gefunden, die Unteilbarkeit zu umgehen: fraktionierte NFT (F-NFT).

Token von Fractional

Dieser Dienst wird unter anderem von fractional.art angeboten. Der Besitzer eines NFT kann dort seinen nicht-fungiblen ERC-721 Token im Protokoll einsperren und sich dafür eine beliebige Anzahl an fungiblen ERC-20 Token erzeugen lassen. Diese Bruchteile kann der Besitzer nun unter anderem als Sicherheit für einen Kredit hinterlegen. Er kann die Token auch nach Belieben ganz oder teilweise an dezentralen Börsen wie UniSwap oder SushiSwap anbieten. Jedermann kann nun über die Börsen die gewünschte Anzahl an Token erwerben. Die Fraktionierung eines NFT ermöglicht eine flexiblere Preisfindung und löst die Liquiditätsprobleme, die mit NFTs verbunden sind. Will man ein hochpreisige Einzelstück kaufen oder verkaufen, muss man immer einige Zeit warten, bis sich ein Handelspartner findet. Bei den Automated Market Makern (AMM) wie UniSwap oder SushiSwap ist hingegen jederzeit ein Tausch möglich. Sie finden eine Übersicht mit vielen hochpreisigen, fraktionierten NFT in dieser Liste. An dieser Stelle wollen wir keine Anlageberatung geben, aber viele NFT-Investoren würden sagen, dass etwa der Preis der Crypto-Punks langfristig bislang nur eine Richtung gekannt hat…

Token von NFTX

Das Fraktionierung ist aber nicht auf einzelne NFT beschränkt. Fractional bietet auch die Möglichkeit an, eine Gruppe aus NFT zusammen zu fraktionieren. Allerdings lassen sich weder einzelne NFT nachträglich hinzufügen, noch lassen sich einzelne NFT nachträglich aus dem Gruppe entfernen. Hier setzt der Dienst von nftx.io an, der eine Art „NFT-Fond“ anbietet. Das Herzstück von NFTX sind die „Vaults“, in denen man NFT einsperren kann und für jedes NFT einen fungiblen „vToken“ im Austausch bekommt. Ein Vault kann alle NFT einer Collection akzeptieren (z.B. alle Punks) oder auch nur eine Auswahl aus einer Collection (z.B. alle weiblichen Punks). Man muss unbedingt wissen, das man mit einem passenden vToken + Gebühr jederzeit ein spezifisches NFT wieder auslösen kann. Hat man beispielsweise einen nicht sehr seltenen/günstigeren NFT im Portfolio und entdeckt im Vault einen selteneren/höherpreisigen NFT, so kann man diese unter Berücksichtigung einer Gebühr gegeneinander umtauschen. Die vToken sind wiederum auf SushiSwap gegen ETH handelbar. Die Oberfläche von NFTX vereinfacht dabei den Zwischenschritt über die Börse. Die ganze Operation „meine ETH gegen einen eingesperrten NFT tauschen“ wird als eine einzige Kauf-Operation angezeigt. Das Gegenteil „meinen NFT für ETH einsperren“ wird als Verkauf dargestellt. Durch die Möglichkeit, NFT hineinzugeben & entnehmen zu können, sowie durch die Preisbestimmung auf der Börse SushiSwap nähert sich der Preis pro NFT dem „floor price“ an bzw. hilft, diesen besser als auf OpenSea zu bestimmen. Das bedeutet ebenso, das der Markt über die Zeit hinweg alle NFT in dem Vault als die eher günstigsten verfügbaren NFT einer Collection bestimmt hat. Sie finden eine Übersicht mit allen emittierten vToken in dieser Liste.

Beispiel: Wir besitzen einen NFT aus einer Premium-Collection und glauben, dass der Floor Preis demnächst korrigieren wird. Wir wollen ihn daher rechtzeitig verkaufen, und stellen den NFT zunächst bei OpenSea zum erhofften Preis ein. Dort findet sich kein Käufer, der den Preis bezahlen will. Nun können wir den Preis bei NFTX prüfen. Gibt es einen passenden Pool und entspricht dort der Preis den eigenen Vorstellungen, so schließen wir den NFT dort ein. Anschließend verkaufen wir die geprägten vToken auf Sushiswap. Dies senkt den Preis der anderen vToken und eine entsprechende Preisfindung hin zum Floor Price wird erleichtert. Glauben wir hingegen, dass der Floor Price demnächst steigt, so investieren wir in den entsprechenden vToken. Wir können jetzt entweder direkt diesen vToken halten oder einen ganzen vToken (sowie die extra Gebühr, meistens 5%, also insgesamt 1,05 vToken) einsetzen um ein NFT herauszulösen und diesen auf OpenSea zu verkaufen.

Gibt es Margin-Trading auf fraktionierte NFT?

Ist die Liquidität groß genug – und bietet die jeweilige Crypto-Börse das Feature an – so lassen sich Coins und fungible Token auf Crypto-Börsen problemlos als Margin-Geschäft mit und ohne Hebel handeln. Bekannte Börsen die dies unterstützen sind Binance, FTX, Bitfinex, Kraken, KuCoin und viele weitere. Bei nicht-fungiblen Token funktioniert das prinzipiell nicht. Die Liquidität (Menge 1) verhindert jedwede Form einer Long- bzw. Short-Position durch eine andere Partei. Auch Terminkontrakte für einzelne NFT lassen sich nicht bilden, dafür ist der Preis viel zu stabil. Eine Preisfindung geschieht immer nur durch einen konkreten Verkauf, wobei Verkäufe nur selten oder gar nicht statt finden.

Unseres Wissens nach gibt es aktuell noch keinen Markt, auf dem man Margin-Trading mit fraktionierten NFT durchführen kann. Dies ist aber nur eine Frage der Zeit, bis sich auf einer der dezentralen Börsen wie Perpetual Protocol, dYdX, Fulcrum oder bei einem der anderen Wettbewerber ein entsprechender Handelsplatz geöffnet wird. Floor Price markets

Gibt es dennoch eine aktuelle Möglichkeit, um auf fallende Kurse setzen? Ja, die gibt es. Es ist nämlich möglich, auf Polymarket Wetten auf einen NFT floor price zu platzieren. Polymarket ist eine Plattform für Informationsmärkte auf der Ethereum-kompatiblen Sidechain Polygon, auf der man die am meisten diskutierten Themen (z. B. Coronavirus, Politik, aktuelle Ereignisse usw.) handeln kann. Das Prinzip ist immer gleich: Es wird eine Frage gestellt, die man mit „Ja“ oder „Nein“ beantworten kann. Zum Anfang stehen die „Ja“ und die „Nein“-Anteile jeweils bei 0,50 $. Sind mehr Marktteilnehmer der Meinung, das die Frage final mit „Ja“ beantwortet wird, desto mehr „Ja“-Anteile erwerben sie. Entsprechend steigt der Preis für ein „Ja“-Anteil. Der Preis für ein „Nein“-Anteil singt entsprechend. Je günstiger der Preis für einen Anteil wird, desto höherer ist wiederum der zu erwartende Gewinn. Dies schafft einen Anreiz gegen die Mehrheitsmeinung zu wetten. Ist die finale Antwort auf die Frage bekannt, löst sich der Markt auf. Die richtigen Anteile sind dann 1,00 $ wert, während die falschen Anteile keinen Wert besitzen. Wenn man Anteile mit dem richtigen Ergebnis besitzt, kann man diese wieder gegen den Stablecoin USDC eintauschen.

Fazit

Mit der weiter wachsenden Popularität und Marktkapitalisierung von Non-Fungible Token (NFT) entwickeln sich auf die Werkzeuge weiter. Um an der Wertentwicklung eines hochpreisigen NFT teilzuhaben, kann man auf fraktionierte NFT setzen. Ebenso ist es möglich, in Anteile an einem Pool aus NFTs zu investieren. Möchte man auf steigende bzw. fallende Mindestpreise (floor price) setzen, so bieten sich Wetten auf einem Informationsmarkt an.
