NFT kaufen – die vollständige Anleitung

Hintergrundwissen zu Blockchain-Token

Read this in English

In diesem Artikel wollen wir weiter auf die verschiedenen Arten von Token auf Blockchains gehen. Wir haben den Anspruch, Ihnen technisch einwandfreie Informationen bieten. Daher gehen wir zum Teil etwas tiefer ins technische Detail.

Die Details aus diesem Artikel ergänzen den Hauptartikel: → NFT kaufen

Was sind fungible Token?

Im Kontext von Blockchains ist ein Token ist ein digitaler Gegenstand, den man besitzen kann. Ein Token hat üblicherweise eine bestimmte Funktion und einen bestimmten Wert. Viele Tokens sind als Wertspeicher, Tauschmittel und Rechnungseinheit gedacht – sie bilden also digitales Geld ab (Payment Token, z.B. USDT). Darüber hinaus gibt es aber auch Token, welche für Abstimmungen verwendet werden können (Governance Token, z.B. UNI), die Funktion von Wertpapieren abbilden (Security Token) oder digitale Gutscheine, die ihren Besitzer zu irgendeiner Art von Zugang auf einer Plattform oder zu einer Dienstleistung berechtigen (Utility Token, z.B. GRT). Viele weitere Anwendungsfälle (etwa Social Token) gibt es oder werden womöglich gerade entwickelt. Allen diesen Token ist gemein, das sie fungibel, d.h. miteinander austauschbar, sind. Ein USDT hat die selben Eigenschaften und den selben Wert wie ein anderer USDT.

Die zweitgrößte Blockchain der Welt nach Bitcoin nennt sich Ethereum. Dort werden meisten Token angeboten. Dies geschieht durch "Smart Contracts" (Intelligente Verträge), welches nichts anderes als ausführbare Computerprogramme auf der Blockchain sind. Dabei hat sich der Standard EIP-20 (auch bekannt als ERC-20) durchgesetzt. Die Token existieren nur innerhalb des Vertrags, der wie eine in sich geschlossene Datenbank ist.

Der Vertrag legt die Regeln für die Token fest (d.h. Name, Symbol, Teilbarkeit, Regeln für den Transfer usw.) und führt eine Liste, welche den beteiligten Benutzern bzw. deren Ethereum-Adressen ihr Guthaben zuordnet. Alle Verträge nach EIP-20 besitzen die selben standardisierten Methodennamen, so dass diese wiederum von anderen Verträgen auf die selbe Art und Weise verwendet werden können. Es gibt z.B. eine Methode um die verfügbare Gesamtmenge zu erfragen oder eine Methode um eine Menge von Token von einem Besitzer zu einem anderen Besitzer zu übertragen. So lassen sich größere Konstrukte, wie etwa dezentrale Börsen oder Kreditvergaben, auf der Blockchain realisieren.

Achtung! Viele fungible Token sind häufig stark durch eine enorm volatile Finanzwelt geprägt. Neue Tokens kommen und gehen, es wird an zentralen und dezentralen Börsen ohne Regulierung gehandelt. Leider werden viel zu oft Investoren durch Betrug (man spricht hier von "rug pulls") um ihre Einlagen gebracht. Der Handel mit neuen, unbekannten Tokens ist nur eine Sache für extrem risikoaffine Investoren – es besteht die Gefahr eines Totalverlustes!

Was sind Coins?

Coins sind die native Währung einer Blockchain, zum Beispiel Bitcoin (BTC) oder Ether (ETH). Mit Coins werden die Computer belohnt, welche das Netzwerk am Laufen halten. Bei Bitcoin und Ethereum nennt man diese Computer "Miner". Die Miner "schürfen" neue Blöcke für die Blockchain. Bei Ethereum führen die Miner beim Erstellen eines neuen Blocks zusätzlich noch Smart Contracts aus. Für diese Dienstleistung werden die Miner mit zusätzlichen Gebühren durch die Nutzer belohnt. Coins sind ebenso nicht-fungibel, können aber nicht programmiert werden. Da Coins das native Asset einer Chain sind, lassen sie sich deutlich kostengünstiger als Tokens transferieren.

Was sind nicht-fungible Token (NFT)?

Wie man dem Namen "Non-Fungible Token" entnehmen kann, sind diese Token nicht miteinander austauschbar. Es gibt von jedem nicht-fungiblen Token nur ein einziges Exemplar, welches durch eine einmalige ID identifiziert wird. Der "Goldstandard" dieser Token richtet sich nach dem EIP-721, ein weiterer konkurrierender Standard trägt die Nummer EIP-1155*. Auf dem ersten Blick scheinen solche Einzelstücke eine seltsame Sache zu sein. Wofür braucht man einen Vertrag, der nur unterschiedliche Tokens verwaltet?

Die Anwendungsfälle ergeben sich daraus, das man für jeden Token auf der Blockchain (on-chain) Metadaten hinterlegt werden können. Handelt es sich um viele zusätzliche Daten, können diese auch auf einer normalen Internetadresse (off-chain) hinterlegt werden. Bei den zusätzlichen Daten handelt es sich um ein JSON-Dokument, das in der Cloud gehostet wird oder das über das InterPlanetary File System (IPFS) bereitgehalten wird. In den Metadaten ist häufig die Internetadresse (URI) von einem Bild, einem Video, einer Audiodatei oder anderen digitale Güter hinterlegt. Auch diese liegen in der Cloud oder in einem Netzwerk wie dem IPFS. Durch die Metadaten und durch die verknüpften Resourcen kann man NFTs als digitale Kunst, Veranstaltungstickets, Sammelkarten, Spielgegenstände oder sogar Eigentumsnachweise für physische Dinge einsetzen. Entsprechende Apps und Webseiten (z.B. der Portfolio-Tracker von DappRadar) zeigen alle hinterlegten Informationen wieder an.

* Mit EIP-1155 kann man Token erstellen, die doch wieder fungibel sind! Man kann damit einen "pseudo-NFT" erstellen, von denen es mehrere limitierte Kopien gibt. Auf dem Marktplatz OpenSea können dann mehrere Personen eine exakt selbe Sache erwerben.
